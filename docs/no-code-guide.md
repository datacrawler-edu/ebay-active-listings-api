# Run from Apify Console

1. Open [the hosted Actor](https://apify.com/datascraperes/ebay-active-listings-scraper?fpr=edudata).
2. Enter one product search under Search keywords and choose the marketplace.
3. Set a small limit. To monitor one seller, enter the exact username in Seller monitor.
4. Start the run and inspect the Dataset after it finishes.
5. Download JSON or CSV. Check SUMMARY when coverage or charges ended the run early.
